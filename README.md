# 萤火画布（Firefly Canvas）

面向 Windows 的本地 AI 无限画布工具。它把图片生成、参考图、提示词节点、生成历史、Agent 节点和 Photoshop 工作流放在同一个可回退的画布里。

## 项目定位

“萤火画布”长期沿着更适合个人创作工作流的方向独立演进，当前重点包括：

- 生成历史可视化、提示词复用和图片直接回到画布
- 图片单击选择、双击预览，减少点击与拖放冲突
- 提示词与对话拆分，支持把选中文字发送为新节点
- 固定比例局部生图、回图原位拼接与边缘羽化
- 自由形状保护蒙版和非破坏式局部修改
- 根据图片参数自动路由模型，不擅自修改宽高和分辨率
- Photoshop 插件联动
- Agent 节点：生成计划、参考图分析、确认执行与结果回填

## Windows 快速开始

1. 下载或克隆本仓库。
2. 首次使用双击 `安装依赖.bat`。
3. 双击 `run.bat`。脚本会检查项目自带 Python 的依赖；依赖不完整时自动使用系统 Python。
4. 等服务就绪后，脚本会自动打开 `http://127.0.0.1:3000/`。
5. 如果启动窗口提示 Python/依赖缺失，先双击 `安装依赖.bat`，完成后再次运行 `run.bat`。
6. 在页面左下角的 API 设置中配置服务地址、模型和 Key。

也可以使用系统 Python：

```powershell
python -m pip install -r requirements.txt
python main.py
```

## 数据与隐私

- API Key 保存在本机 `API/.env`，不会纳入 Git。
- 画布、生成历史、素材、输出图片和日志都属于本地运行数据，不应提交到公开仓库。
- 提交代码前请先检查 `git status`，避免误传密钥、图片和个人数据。
