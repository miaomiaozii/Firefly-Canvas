# 萤火画布（Firefly Canvas）

面向 Windows 的本地 AI 无限画布工具。它把图片生成、参考图、提示词节点、生成历史、Agent 节点和 Photoshop 工作流放在同一个可回退的画布里。

## 项目定位

“萤火画布”长期沿着更适合个人创作工作流的方向独立演进，当前重点包括：

- 生成历史可视化、提示词复用和图片直接回到画布
- 图片单击选择、双击预览，减少点击与拖放冲突
- 提示词与对话拆分，支持把选中文字发送为新节点
- 固定比例局部生图、回图原位拼接与边缘羽化
- 自由形状保护蒙版和非破坏式局部修改
- 根据图片参数自动路由模型，不擅自修改宽高和分辨率
- Photoshop 插件联动
- Agent 节点：生成计划、参考图分析、确认执行与结果回填

## Windows 快速开始

1. 下载或克隆本仓库。
2. 首次使用双击 `安装依赖.bat`，安装完成会创建桌面和开始菜单快捷方式「萤火画布」。
3. 双击「萤火画布」。服务就绪后自动打开浏览器；重复打开不会启动第二个服务。
4. 从 Windows 通知区域的萤火画布图标打开页面、重启服务、切换开机自启或退出。
5. 在页面左下角的 API 设置中配置服务地址、模型和 Key。

`run.bat` 保留给开发启动。若开发服务仍占用端口，先通过原方式停止它；托盘不会接管或终止其他进程。
「刷新缓存.bat」不会启动或停止服务，只清理代码的 Python 字节码、刷新前端资源版本并检查运行中的后端。纯静态修改成功后重新载入页面即可；若提示「后端已更新，需要重启服务」，请在托盘菜单选择「重启服务」，或在原服务窗口按 Ctrl+C 后重新运行 `run.bat`，再重新载入页面。旧服务未提供版本信息、连接失败或版本无法确认时返回失败，不会自动重启。自定义端口可运行 `powershell -File tools/refresh-cache.ps1 -ServiceUrl http://127.0.0.1:<端口>`。身份边界见 [后端版本合同](docs/design/backend-version-488.md)。

也可以使用系统 Python：

```powershell
python -m pip install -r requirements.txt
python main.py
```

## 数据与隐私

- API Key 保存在本机 `API/.env`，不会纳入 Git。
- 画布、生成历史、素材、输出图片和日志都属于本地运行数据，不应提交到公开仓库。
- 提交代码前请先检查 `git status`，避免误传密钥、图片和个人数据。
