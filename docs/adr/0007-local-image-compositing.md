# 局部图片编辑由本地画布完成合成

核心画布提供独立的局部编辑节点，接收任意图片输出节点作为上游，并在节点中执行“局部修改”或“局部保留”。局部修改只向在线模型发送固定比例矩形选区裁出的局部图，结果返回后在本地按原坐标羽化拼回；局部保留向模型发送完整原图，结果返回后使用本地自由形状保护蒙版恢复原图细节。两种模式都不向模型发送蒙版，也不改写上游原图节点。

## Consequences

- 画布需要统一且可测试的坐标换算、裁切、蒙版、羽化和合成模块。
- 局部修改支持固定生图比例的矩形选区；局部保留支持自由手绘、套索和曲线选区。
- 每次操作必须保留原图、模型返回结果、蒙版或选区数据以及最终合成结果，以支持撤销和复现。
- 在线模型只负责生成，选择区域的解释和回图原位拼接完全属于本地画布。
- 局部编辑节点输出新的合成图片供下游连接，上游图片节点始终保持不变。
- 核心画布只提供一种局部编辑节点，节点内部选择局部修改或局部保留模式，并复用同一套生成、合成和输出生命周期。
- 局部编辑节点使用三个显式输入口：单一 `原图`、可多选的 `参考` 和可组合的 `提示词`；不得按连接顺序猜测图片角色。

## Validated compositing contract

- 选区持久化为原图像素坐标，使用整数半开区间 `[left, right) × [top, bottom)`；视口坐标只在交互边界换算一次，不得写入合成状态。
- 缩放视口的每条选区边独立按原图与显示图尺寸换算并取最近整数；裁切、返回图缩放、羽化半径和回拼位置之后全部使用原图像素。
- 固定比例必须在换算后的原图矩形上再次校验；模型返回的局部图只允许缩放一次，目标尺寸严格等于该原图矩形。
- 局部修改的羽化蒙版限制在原图矩形内，矩形外像素必须逐像素保持不变。
- 局部保留蒙版统一定义为 `255 = 恢复原图`、`0 = 保留完整模型结果`；手绘、套索和曲线最终都栅格化到同一张原图尺寸蒙版。
- 裁切、缩放、羽化与合成全程保留 RGBA；复现一次操作必须持有原图、模型返回图、原图坐标选区或原图尺寸蒙版、羽化半径和最终输出。

## Validation

2026-07-21 在 Windows 10.0.26200、AMD64、CPython 3.10.11、Pillow
12.3.0 和 D: 盘上完成 Issue #3 的离线 4K 原型。原型源码、单命令
benchmark、完整 RGBA PNG、机器可读断言结果与 SHA-256 保存在独立的
[`prototype/issue-3-local-image-compositing`](https://github.com/miaomiaozii/Firefly-Canvas/tree/5649ef8d3de2dfdc7df30a64c08ac6f46018f57b/prototypes/adr0007-local-image-compositing)
分支提交中，不并入正式产品代码。

原型把 1280×675 缩放视口中的 16:9 选区准确映射为 4096×2160 原图的
`(704,352)–(3008,1648)` 半开矩形，得到 2304×1296 裁图；完整 4K 回拼
与独立组装的期望图逐像素一致，变化边界与选区完全相同，坐标误差 0 px。
矩形与自由形状蒙版的全方向最大相邻 8-bit 步进分别为 6 和 4，最终 RGBA
固色接缝探针同样为 6 和 4。手绘、套索和曲线保护区的原图 RGBA 核心像素
完全恢复；透明通道覆盖了局部修改 `0 → 156` 与局部保留 `64 → 0` 两条
实际合成路径。所有断言通过，Standards 与 Spec 修复后复审均为 0 findings。

该证据接受的是上述坐标与合成约束，不是原型实现。正式模块仍须重写，并在
核心画布局部编辑节点的可观察接口上继续覆盖行为测试。
