# 节点创建来源、人工编辑保护与局部撤销兼容

## 背景

Agent 产出的节点可以由人继续编辑。谁创建节点、后来是否有人投入编辑、以及撤销应恢复哪些值，是三个不同的问题。按节点类型猜来源、按数组位置匹配媒体、或用整幅旧画布覆盖现状，都会把不相关的内容算进当前动作。

## 决定

### 来源与人工改动分开记录

- `createdBy` / `agentNodeId` 记录**本次创建**的来源，不是权限，也不是最后的操作者。Agent 来源必须来自明确创建上下文且带有效 Agent 节点 ID，不能从节点类型、连线或源节点继承。人工编辑既有节点不改变其创建来源。
- `userTouchedAt`（T）记录实际持久人工改动的 epoch 毫秒数。`promptEditedByUser`（P）仅随人工提示词正文或结构的实际变化置 `true`；布局、参数、媒体等变化只记 T，不清已有 P。只标真正改变的存活目标；例如连出关系不改变源节点的输入。查看、同值、取消、自动写回和恢复不冒充人工编辑。
- `canvas.list_nodes` 投影规范值但不回填旧画布。只有有效的 Agent 来源及 ID 才投影为 Agent；其它来源投影为 user/null。T 独立校验，P 只把严格 `true` 投影为真。投影默认值不改变原字段的存在性。这不是整个页面只读路径绝不写盘的保证：B09 中刷新触发了客户端 PATCH，保存了 composer 的 `runSettings`，但没有补写旧节点的四个归属字段。
- 人工新建、显式节点复制和用户生成的**新节点**初始化为 `user / null / null / false`，使用新 ID 和创建时间；Agent 新节点按本次创建上下文初始化来源，T/P 为 null/false。通用 clone 不承担该规则。复用既有节点、撤销、重做、媒体恢复不是新建，不重新初始化身份。停靠/浮动同样是同一实体（[ADR 0028](0028-agent-node-dockable.md)）；实际人工持久布局改动记 T，窄视口适配和折叠不记。

### 局部历史与增量保存

- 新历史条目的 `actionDelta` 只恢复动作涉及的持久字段，包含四个归属字段的**存在位和值**；不把缺失、null 和 false 归成一类。集合按实体身份合并，保留与动作无关的并发节点、成员和产物。这不保证任意同字段并发都能合并。无净变化不新增有效步骤，也不使 redo 失效。
- 提示词**节点正文**连续编辑在 1000ms 非 IME 停顿或失焦时封为一步，组合输入结束后处理最终文本。只记录该节点的正文及 T/P，不把同时发生的其它画布变化收进去。改回原文还原原 T/P，不新增历史。这不是所有 composer 或参数入口的通用会话规则。
- 运行期 pending journal 保留未确认的更改。保存只确认其冻结的 checkpoint；以纯服务器基线接收响应，再重放未确认更改，不把合并视图当成已保存状态。撤销即使回到旧服务器值也可能是新的待保存意图。
- 媒体优先以可靠输出项身份匹配；`asset_id` 或旧 URL 仅在匹配唯一时用作后备。冻结的导入请求可以和响应配对，但不能把响应按下标套进实时数组。不能证明身份时显式冲突，不确认待保存意图，也不安装或消费冲突的 delta 历史。硬删原件字节不能靠撤销保证找回。自动归档失败只补偿其归档变化，不是整项目事务回滚。
- 旧 before-only 历史继续按原整快照语义读取，不猜 after、不隐式迁移、不因升级清栈。它不能承诺保留其后的远端变更，也必须经过未决意图守卫。#251 后撤销栈异步持久化到每项目 `ops.db` 的既有 undo 租户；栈持久化与画布保存不是原子操作，也不是项目版本树。
- #427 另行跟踪两个已知 UI/持久化差异：原图删除经工具栏撤销后，栈已空而按钮可能暂仍可用；手动恢复原图后，首次读取持久栈仍可能看到旧令牌。不要用按钮是否可用代替栈检查，也不要把手动恢复等同于消费原撤销令牌。

### 对话和项目级恢复边界

- **D2：发送不新增撤销步骤。** 发送已交给服务端执行，客户端没有可信的发送前状态可供恢复。本地气泡或 outbox 保存不记 T。人工消息第一次正式登记时，在同次 CAS 中登记消息、消费同 key 占位/意图并用消息时间更新 T（不降低既有有效 T）；不改来源/P。同 key 回执或恢复不再盖 T。Ctrl+Z 不提供取消已登记消息、回退其 T、取消外部请求或退费的保证。
- **D3：未决意图冲突时显式拒绝。** 对话有待恢复 outbox 或正式 pending 用户请求时拒绝人工节点复制，不重写 key、不伪造终态。undo/redo（含旧条目）若会引入、移除、改写或重排 live 未决意图，拒绝安装候选并保留原栈与合法执行队列。异步恢复按原 key 查证，并在查询后及发起请求前复核项目、画布、节点和原意图；拒绝不等于取消已发请求。
- **D4：项目级入口不保证永久防重放。** 整项目复制、版本或备份恢复保留节点四字段及缺字段形态，不按逐节点 Ctrl+D 重置来源。活动任务守卫和键去重不能证明恢复旧状态后绝不重放，也不意味着必然重放。A2 不引入 A3 的 `agent_ops`/`op_id`、永久所有权账或新 sidecar 租户。
