# 使用 .fly 作为项目交换文件

萤火画布运行时使用项目目录，导出、备份和分享时打包为单个 `.fly` 文件。`.fly` 使用可校验的 ZIP 容器，包含项目元数据、画布、生成历史和项目媒体原件；导入时验证并解包成新的项目目录，不直接在压缩包内编辑。

## Consequences

- 项目包需要包含格式版本、项目标识、文件清单和校验值。
- API Key、全局设置、项目回收区、临时文件和可重建预览不得进入项目包。
- 图片、视频和音频等已压缩媒体默认使用存储模式，避免重复压缩造成长时间卡顿。
- 导入必须防止路径穿越和覆盖现有项目；项目标识冲突时生成新的本地项目标识。
