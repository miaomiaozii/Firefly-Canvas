# ADR 0030：Windows 托盘拥有本次启动的服务

状态：接受（#419）。

## 决策

- 「安装依赖.bat」通过依赖验证后为当前用户生成桌面、开始菜单快捷方式；不改默认浏览器、不覆盖指向其他安装的同名快捷方式。开机自启默认未启用；仅由托盘菜单创建或删除当前安装的 Windows「启动」快捷方式。登录时启动托盘、不主动打开页面。
- Windows Script Host 在隐藏窗口中运行 Windows PowerShell 5.1；WinForms 提供通知区图标，无需新增 Python 包。相同 Windows 会话、用户、安装路径和端口通过本地命名 mutex 单实例；第二次启动只通过命名事件请所有者打开页面，启动未完成时等就绪再打开。
- 托盘创建无窗口的 Python 子进程，将其在恢复执行前加入不可脱离的 Windows Job Object，只继承专用的标准输入输出管道；之后发出启动握手。子进程用独立的启动日志；只有该进程实际绑定监听器后才写本次就绪标记。不会探测 HTTP 成功后误接管其他程序，也不会按端口或进程名杀进程。
- 「重启服务」和「退出」关掉私有 stdin，服务收到 EOF 请求 Uvicorn 正常关闭。托盘等候服务退出（最多 8 秒），再关闭 Job，清理仍存活的所有后代以及日志管道；重启在旧 Job 关闭后建立新 Job，退出则销毁托盘并释放单实例锁。托盘意外死亡时，操作系统关闭 Job，确保服务和 sidecar 不被遗留。若无法把子进程加入 Job，启动失败，不允许无监管运行。
- 原有 `run.bat`、刷新缓存和便携包启动方式不变；它们不是托盘所有的服务。遗留服务占用端口时显示中文错误。测试只用隔离端口、数据目录和快捷方式目录。

## 代价

Job 受 Windows 宿主进程和企业策略约束；不支持组合 Job 的环境会报告启动失败。PowerShell/Windows Script Host 被组织禁用的机器仍可使用原有开发入口，不使用替代手段绕过组织策略。
