# 萤火画布使用独立发布渠道

现有自动更新器仍指向 `hero8152/Infinite-Canvas`，继续使用可能用作者版本覆盖已经分化的萤火画布。第一阶段删除自动检查、文件差异下载和覆盖更新，只保留萤火画布自身版本显示；未来升级只能来自 `miaomiaozii/Firefly-Canvas` 的正式发布渠道，并另行设计备份与迁移机制。

## Consequences

- 删除指向作者 GitHub 和 ModelScope 仓库的自动更新常量、接口和界面提示。
- `upstream` 远端只作为人工查看原作者变更的只读来源，不能成为应用运行时更新源。
- 不再整体合并作者主分支；只选择性吸收单个修复或思路，并按萤火画布现有结构重新实现或 cherry-pick 后测试。
- 在独立发布机制完成前，用户通过 Git 或手动下载更新程序代码，项目库不参与代码更新。
