# 以智能画布作为产品核心

萤火画布选择以现有智能画布为基础继续迭代，而不是以功能更完整但较难使用的普通画布为核心。普通画布暂时保留为经典画布，用于旧数据兼容和能力迁移；对话节点等有价值的能力将迁入核心画布，完成迁移后再决定删除经典画布。

## Consequences

- 新功能只以核心画布的交互模型为准，不要求继续同步到经典画布。
- 经典画布中的能力需要逐项判断是迁移、重做还是放弃，不能直接复制其复杂交互。
- 现有经典画布只有测试数据且不迁移；相关能力评估完成后可以直接删除经典画布实现。
- 应用主入口收敛为“项目列表 → 项目唯一的核心画布”；当前 iframe 功能大厅及各独立业务入口不再保留。
- API、模型、CLI、项目库位置、主题、语言和 PS 连接状态统一从单一全局设置界面进入，素材与历史从核心画布内部进入。
