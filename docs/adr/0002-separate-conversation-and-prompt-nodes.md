# 对话节点与提示词节点严格分离

核心画布使用独立的对话节点保存多轮交流，提示词节点只保存可供生成操作消费的创作指令。对话历史不会整体或隐式进入生图请求；用户必须明确选取对话内容并生成提示词节点，从而让实际传给模型的内容可见、可编辑、可回退。

## Consequences

- 对话节点需要独立的消息存储、折叠状态和多模态参考输入。
- 提示词节点继续保持轻量，不承载聊天界面或历史。
- 任何“对话内容进入生成流程”的动作都必须在画布上产生可观察的结果。
- 从对话提取提示词时只复制用户选中的文字；新节点保留来源节点和消息标识，但不自动创建图连线。
