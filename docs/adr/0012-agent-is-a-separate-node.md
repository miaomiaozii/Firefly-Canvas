# Agent 使用独立节点

核心画布把对话节点与 Agent 节点拆分。对话节点只负责多轮交流和提示词提取；Agent 节点负责根据目标规划并调用获准工具。两者不通过模式切换混用状态、权限或界面。

## Consequences

- Agent 的消息、计划、运行状态和工具调用历史只属于 Agent 节点。
- 每次 Agent 工具调用必须在画布上产生可见任务或结果，并进入当前项目生成历史。
- Agent 不能把隐藏的整段上下文直接注入普通生成节点。
- PS 连接器中不再提供 Agent 界面；Agent 只存在于核心画布。
- 第一阶段 Agent 只能读取显式连接的提示词和媒体、创建提示词节点、发起在线图片或视频生成并创建结果节点。
- 第一阶段 Agent 不得删除项目、媒体或节点，不得修改全局设置、API Key 或项目库，不得跨项目访问或直接控制 Photoshop。
- Agent 默认先生成可见执行计划，列出任务、模型类型、数量和参数；用户确认执行计划后才能调用在线服务。
- 执行期间不得增加计划外的生成任务；需要新增时必须更新计划并再次取得确认。
