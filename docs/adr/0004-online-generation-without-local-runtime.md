# 保留在线多媒体生成并移除本地运行时

萤火画布保留在线图片生成、在线视频创作以及相关的多模态参考输入，但不再保留 ComfyUI、本地模型运行或工作流执行能力。相比继续兼容原项目的本地生成体系，项目把维护投入集中到在线模型路由、参考素材、局部编辑、视频创作、历史复用和 Photoshop 联动。

## Consequences

- 删除 ComfyUI 设置入口、连接逻辑、工作流导入执行、内置工作流和相关专用页面。
- 不把 Z-Image、Klein 或细节增强功能迁入核心画布；细节增强作为独立能力整体删除。
- 保留在线视频生成、视频参考、音频参考、视频预览和抽帧能力。
- 音频只作为多模态参考或视频音轨存在，暂不建设独立音频生成、剪辑或音频工程界面。
- 新的生成能力必须通过在线服务商接入，并遵守统一的生成请求和结果模型；允许直接 HTTP 接口或服务商 CLI 适配器。
- CLI 适配器可以保留，前提是模型推理发生在远程服务中，且不引入本地模型或工作流运行时。
- 删除前需先确认代码、测试和用户项目中不存在必须保留的 ComfyUI 数据。
