# 模型路由不得修改用户生成参数

萤火画布根据媒体类型、参考素材和生成参数自动选择兼容的在线模型，但路由职责仅限于选择服务商与模型。宽高、比例、分辨率、参考素材数量和媒体类型是用户明确输入，系统不得为了让请求成功而静默修改或降级。

路由/调度层可以**选择** provider,但不得**修改**用户提交的生成参数（含 basename 重写类映射）；参数重写即违反本 ADR。

## Consequences

- 路由器需要维护模型能力信息，并返回最终选择及选择理由。
- 没有模型完整支持请求时，生成必须停止并指出不兼容参数。
- 生成历史必须记录用户请求参数以及实际执行的服务商和模型，保证结果可解释。
- 默认路由模式为自动；手动固定模型仍需通过相同能力校验。

## 画布生图的服务商边界（#465）

自动档只在节点所选服务商**已勾选**的生图模型中匹配，不跨服务商，也不使用仅发现但未勾选的模型。固定档同样只能使用该服务商已勾选的模型。没有可用模型时提示去全局设置勾选，或由用户主动切换服务商。

旧节点没有选服务商时，显示「请先选择服务商」并禁用生成，不以主服务商或画布默认值补齐，也不改 `runSettings`。服务端和 `generate.trigger` 独立拦截，不发上游请求、不扣额度。
