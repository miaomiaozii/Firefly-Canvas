# 模型路由不得修改用户生成参数

萤火画布根据媒体类型、参考素材和生成参数自动选择兼容的在线模型，但路由职责仅限于选择服务商与模型。宽高、比例、分辨率、参考素材数量和媒体类型是用户明确输入，系统不得为了让请求成功而静默修改或降级。

路由/调度层可以**选择** provider,但不得**修改**用户提交的生成参数（含 basename 重写类映射）；参数重写即违反本 ADR。

## Consequences

- 路由器需要维护模型能力信息，并返回最终选择及选择理由。
- 没有模型完整支持请求时，生成必须停止并指出不兼容参数。
- 生成历史必须记录用户请求参数以及实际执行的服务商和模型，保证结果可解释。
- 默认路由模式为自动；高级选项允许固定服务商或具体模型，但手动固定仍需通过相同能力校验。
