# 删除原图在项目范围内生效（已由 ADR-0014 取代）

用户执行“删除原图”表示明确否定该生成结果，而不是清理缓存或只隐藏历史记录。系统应从项目中移除该生成原件及缩略图，清除所有节点和历史记录对它的直接引用，并把生成它的节点回退到保留提示词、参考素材和模型参数但没有结果的状态。

## Consequences

- 使用该原图作为输入的下游节点会移除这项输入，并显示上游素材已删除的状态。
- 已经生成完成的下游媒体不会被级联删除，除非用户分别删除它们。
- 删除操作必须进入项目撤销记录；可撤销期间文件保存在项目内部临时回收区，过期后才物理清理。
- 项目内部回收区保留删除原件 7 天；项目导出不包含回收区，用户执行清空时立即物理删除。
- “删除历史记录”和“删除原图”是不同操作，界面和接口不得混用。ADR-0014 生效后，本决策中的项目范围能力只能通过显式命名的 project-wide 操作触发，不能由“删除当前原图”接口缺失输出项身份时降级触发。
- “取消生成任务”也是独立操作；删除旧记录或旧原件不得取消复用同一结果节点的新任务，也不得移除其他任务的状态卡。
- 正被运行中任务直接作为输入的原件不得删除，必须先取消依赖任务。
- “项目清理”只允许从项目列表对已关闭且无任何活跃任务或会话的项目执行，并只永久移除具有明确失败或临时残留来源、可证明没有项目内容引用、生成记录、恢复所有者或待交接消费者的孤立媒体。它不是删除原图或删除历史记录，不进入回收区且不可撤销。
- 用户导入或主动保存到项目素材的媒体本身属于项目，即使当前没有节点或历史引用也不得由项目清理删除。来源不明、归属不确定、文件损坏或无法完整解析时必须跳过或拒绝整次清理。
