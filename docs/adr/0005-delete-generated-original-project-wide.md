# 删除原图在项目范围内生效

用户执行“删除原图”表示明确否定该生成结果，而不是清理缓存或只隐藏历史记录。系统应从项目中移除该生成原件及缩略图，清除所有节点和历史记录对它的直接引用，并把生成它的节点回退到保留提示词、参考素材和模型参数但没有结果的状态。

## Consequences

- 使用该原图作为输入的下游节点会移除这项输入，并显示上游素材已删除的状态。
- 已经生成完成的下游媒体不会被级联删除，除非用户分别删除它们。
- 删除操作必须进入项目撤销记录；可撤销期间文件保存在项目内部临时回收区，过期后才物理清理。
- 项目内部回收区保留删除原件 7 天；项目导出不包含回收区，用户执行清空时立即物理删除。
- “删除历史记录”和“删除原图”是不同操作，界面和接口不得混用。
