# Agent 节点可停靠：同一实体、三种呈现

Agent 节点除浮动在画布上外，可停靠到画布左/右边缘（贴边、全高、不随画布缩放/平移）。停靠是**呈现位置**，不是新实体：会话、消息、草稿、工具状态仍全部属于该节点（见 [ADR 0012](0012-agent-is-a-separate-node.md)）。

## 决定

- 数据模型：`node.dock ∈ {'left','right'}`（无该字段或 null=浮动）与 `node.w` 随画布按项目持久化；收起态和手动展开标记分别只在页面内存 `agentDockCollapsed` / `agentDockUserExpanded` Set 中，不写节点、不触发保存。旧 `node.dockCollapsed` 在节点规范化时删除，`canvasForStorage` 再防御剥离。唯独加载差异基线使用 `preserveLegacyDockCollapsed:true` 在独立克隆中保留磁盘旧值，使未改动节点也会在下一次增量保存产生删除旧字段的 upsert；正常保存没有该选项。
- DOM：停靠态的节点 DOM 挂在 `#shell` 下的停靠槽 `#agentDock`（与 `#world` 平级），不进 `#world`，因此不随 `#world` 的 translate+scale 变换。按钮切换或被另一个 Agent 替换时**不动视口、不改 `node.x/y`**：浮动态坐标原样保留，取回原处落回。拖出则按落点换算世界坐标（`screenToWorld` 后 x/y 各减 20 并取整），不是原坐标取回。
- 三种形态同一实体：消息/流式更新走 TUI 的 `renderAgentNode` 就地路径（按 `[data-id]` 全文档查找，元素在停靠槽里同样工作）；全量 `render()` 跳过停靠中的节点，不触碰停靠槽里的现成元素——因此输入/IME 组合永不被全量重建打断（与 #314 草稿/IME 保护同一原因）；只有显式切换形态才搬 DOM，搬前抓焦点/选区、搬完恢复。目标或被替换者正在 IME 组合时，整次切换请求 `{nodeId,dockSide}` 挂在阻塞者的 `pendingDock`，等其 `compositionend` 后执行，不提前取回另一节点。
- 交互：节点头按钮「停左 / 停右 / 收起 / 展开 / 取回」；停靠态拖节点头拖出画布落回浮动（落点=世界坐标）。不做浮动→停靠的边缘吸附拖拽（误触风险，spec 只要求拖出）。
- 停靠宽度复用 `node.w`（与画布内布局同公式：有效 `node.w` 否则 **480**，下限 330）；收起态固定 44px 窄条。#421/#424 门 3 当前实现把新建宽度与无有效宽度时的回退从 382 调到 480px，不批量改写已有显式 `node.w`，旧 382px 仍按 382px 呈现。详见下节。
- 窄视口（<900px，或 面板宽+480px > 视口宽）自动收起为窄条；**只自动收起、不自动展开**，展开由用户手动。手动展开抑制本次页面后续自动收起；刷新后两种内存标记均消失，只按当前视口重判。窄条边距按 12px 间距 + 44px 宽度让位，不沿用展开宽度。
- 唯一停靠：停靠第二个 Agent 时，先取回其它 Agent，再停靠目标（同侧、异侧均相同），原坐标及会话/草稿不动。旧数据同时有多个有效 dock 时，按 `canvasState.nodes` 数组顺序保留第一个 Agent 的有效 dock，其余置 null；非 Agent 的 dock 也清除。在 `render()` 的 world 过滤前规范化，`syncAgentDock()` 再兜底；兼容清理随下一次内容保存落盘，不因收起或同步触发保存。
- 历史验证视口偏离（#407）：批准的第四档截图是 900px；旧交付改用 880px，是对批准验证方案的偏离，不是代码修复。当时默认宽度 382px，900px 不触发自动收起、880px 会触发。门 3 没改 <900px 或“面板宽+480px”阈值，但默认面板改为 480px 后，900px 也会因第二个条件收起；不能把旧截图当成当前门 3 证据。
- 层级：停靠面板 `z-index:85`，与面板类浮层（提示词预设面板等）同档，低于历史抽屉（86）——符合 spec「排在面板类浮层和历史抽屉之间」。85 与 86 之间无整数可用，取 85 的依据是停靠面板与历史抽屉在**水平方向让位**（抽屉 `left/right` 加 `#shell` 上的 `--agent-dock-left/--agent-dock-right` 变量让开停靠面板，包含后置 Foundation history rail 规则和窄屏 media 查询；零重叠由交付截图及双方 DOMRect 验证），同档的 preset-panel 只出现在提示词节点附近。小地图、左上工具栏同样让开。
- 已知代价：停靠节点若有画布连线，连线端点仍画在 `node.x/y` 世界坐标（空位），不重路由到面板边缘。

## #421 / #424：r3 输入区与用户消息导航（实施门 3）

本节描述门 3 实现。上方 accepted 是既有停靠决策的状态，不是本门放行；截图矩阵、浏览器及完整 Store 证据见门 3 交付记录。产品合同见 [CONTEXT.md](../../CONTEXT.md)，原子设置、`expected` schema 与专用设置 undo/redo 见 [ADR 0024](0024-codex-per-turn-host-bridge.md)。

### 同一节点的输入区与宿主视图

- 浮动/左停靠/右停靠复用同一 TUI：保留外层节点头的标题、真实状态、会话框/参考框、停靠与更多操作，不再生成重复的内部会话头。正文可滚动，底部输入区为多行输入（初始三行、最小 96px）+ 参数工具条 + 操作行；窄节点工具条允许换行，不以强改旧节点宽度适配。
- 参数工具条为 Pi/Codex 宿主选择、模型、思考、自治确认档位。自治值仍为 cautious/standard/autonomous，UI 显示“每张 / 每批 / 无需”；这不是思考档位。模型/思考共用原生能力选择器，只有打开、切模型、重试时调 capabilities，普通 render 不探测；无法确认就显式不可用，不造枚举，不暴露 ultra。旧 effort 不适用于新模型时明确确认 model + null effort 一起提交，默认未确认仍由后端拒绝，不静默降档。
- 操作行保留附件、思考过程显隐、运行中 steer/排队、停止、发送；分叉、Pi 分支选择、外部 CLI 接管、只读查看另一宿主在“更多”中。Codex 不假称支持 Pi 分支。首次选宿主确认新开独立会话，有绑定时确认恢复该宿主自己的会话与参数，不把 UI 选择本身当作原生启动完成。
- 参数在设置请求/切换确认、IME、附件处理，以及活跃宿主 busy、启动/连接/重试、确认、输入回执/排队、回放、未完成 stop 时锁定；后端 busy 检查仍是权威。停止送达只显示等待结束，终态事件或状态核验前不提前解锁参数；核验失败有可重试提示。
- requested 是保存意图，submitted 是实际提交参数，effective 才是可信宿主回读。提示同时说明来源；Pi 仅有严格 ACK/state 回读才显示生效，Codex 继续区分“已设置/已提交”和“生效未确认”（effective=null），模型能力不是当前生效证据。
- `activeHost` 来自权威节点，`viewHost` 是页面当前查看宿主。只读查看仅 GET 对应宿主 events，不改活跃宿主、不启动宿主，不开放发送/设置；“返回当前会话”和“切回此宿主继续”是不同动作，后者需确认并走 `/settings`。
- 草稿、输入焦点/选区、阅读锚点/未读、待发送附件/引用、工具/思考展开、导航预览等按宿主留在页面内存，不写节点；收起/手动展开标记同样不保存。切换视图隔离 socket/回放回调，迟到事件不能串入另一宿主；页面刷新后消息由宿主隔离的历史重建，不把临时视图当持久会话副本。
- 权威设置回包及设置 undo/redo 接收后，`applyAgentHostSettingsAuthority` 同步活跃宿主和 `effort_state`，再 `renderAgentNode` 就地刷新。全量 render 跳过停靠 DOM 不等于停靠参数可以不更新；不得靠普通 autosave 写回乐观设置或历史原生绑定。

### 仅用户消息的独立导航

- `canvas-agent-navigation.js` 是独立 classic script，在 TUI 前加载；TUI 显式注入阅读区域、跳转回调及带稳定 timeline key 的**用户消息 DOM**。助手、工具、系统、思考段不生成刻度，不复制整条时间线或消息内容到另一套持久模型。
- 左侧 24px 导航热区与正文选区分离；刻度高 2px，普通宽 6px、当前宽 12px。常规中心间距 16px，两端内缩至多 12px；超长对话均匀压缩到轨道可用高度，不丢尾部项。压缩后由统一轨道按指针 y（含节点缩放换算）选最近中心，不依赖重叠按钮抢命中；按钮不接收指针事件，但保留键盘目标。
- 当前刻度随可见阅读位置更新：每条用户消息连同其后的助手/工具段，直到下一条用户消息，视为该用户的阅读段；不是永远标记数组末条。跳转只滚动节点正文，不平移画布；指针按下防止画布拖拽及输入框焦点/选区丢失。键盘用单一 Tab 入口、上下/Home/End 移动、Enter/空格跳转，Escape 关闭预览。
- hover/focus 预览用 body portal 的 fixed 视口坐标，不随浮动节点缩放、不受节点裁剪；纯文本显示来源“你”及最多两行正文，常规宽 200px。优先画布外侧，空间不足寻找视口内安全行/列，不覆盖注入的阅读区域；无安全位置就隐藏，不以遮挡兜底。
- 滚动只更新几何/当前标记，不替换时间线或导航子节点、不强夺焦点；refresh 按稳定 ID 协调条目。正文重绑、节点取回/卸载/删除时销毁旧导航、portal、观察器、监听与待执行帧，实例之间不共享预览或当前项。
