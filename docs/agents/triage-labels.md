# Triage 标签

工程技能使用五种固定的分类角色。本文件把规范角色映射为本仓库实际使用的 GitHub 标签。

| 规范角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage（待分类）` | 新问题，等待维护者分析分类 |
| `needs-info` | `needs-info（待补充信息）` | 信息不足，等待报告者补充 |
| `ready-for-agent` | `ready-for-agent（可由智能体处理）` | 规格完整，可以交给 Codex 实施 |
| `ready-for-human` | `ready-for-human（待人工处理）` | 需要维护者亲自判断或操作 |
| `wontfix` | `wontfix（不处理）` | 已决定不实施或不继续处理 |

技能提到规范角色时，必须使用本表对应的完整 GitHub 标签字符串。
