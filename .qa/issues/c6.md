## Parent issue

#294（跟踪）

## What's wrong

删除与撤回（画布核心安全网）没有端到端验收：删节点/连线/框选批删是否生效、撤回能否逐步恢复（含位置与连线）、误删后撤回链是否完整，均无自动校验。

## What I expected

端到端新增场景：
- 选中节点删除 → 断言节点与相关连线消失
- 撤回 → 断言节点按原位置恢复、连线复原
- 连续多操作后逐级撤回/重做 → 断言状态栈一一对应
- agent 触发的画布写操作是否也进入同一撤回链（行为一致性断言）

## Steps to reproduce

1. 删除节点、按撤回
2. 观察：功能存在与否无自动断言保护

## Blocked by

None — can start immediately

## Additional context

用户明确点名「删除撤回验收」。撤回链若与 agent 写操作不互通，单列缺陷另开 bug。
