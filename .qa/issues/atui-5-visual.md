# 【Agent TUI】视觉语言不统一 + 样式层重复/死亡（两代样式共存、思考开关激活态样式失效）

验证人：QA（代码审计 + 实操观察，2026-11-13）。严重度 S5。含用户要求：参考成熟 web 聊天/TUI 界面样式。

## 发生了什么
1. Agent 卡片内按钮图标是 emoji（📎💭↪⏳⏹，static/js/canvas-agent-tui.js:927-931），画布其余区域统一用 lucide SVG 线性图标（如 static/js/smart-canvas.js:9217-9227 的节点动作按钮）→ 视觉语言混杂，emoji 跨系统渲染不一致。
2. 思考模式开关的激活态样式失效：JS 写出的是裸属性 `agent-tui-btn-active`（canvas-agent-tui.js:928），CSS 选择器却是类选择器（static/css/smart-canvas.css:4141）→ 开/关状态没有视觉反馈。
3. 节点头上的 Agent 状态预览被 css:451-452 永久隐藏 → 不打开卡片看不到节点状态（设计意图与实现矛盾）。
4. 样式层重复/死亡：`.agent-node-card/.agent-node-heading`（css:199-244）JS 零引用；`.agent-tui-input` 两条同名规则互相覆盖（css:4095 死、css:4317 活）。两代样式共存，改样式像拆雷。

## 我期望看到什么
- 图标统一 lucide SVG；激活态有明确视觉反馈
- 样式单一来源，删除死样式层
- 参考成熟 web TUI/聊天界面（消息气泡/工具折叠/状态徽标的间距、配色、层级）做一轮视觉对齐

## 复现步骤
1. 观察 Agent 卡片头部图标与画布其他节点图标（风格对比）
2. 切换思考模式开关 → 按钮无激活态变化（截图对照，QA 可补）
3. 不选中节点看节点头 → 无状态指示
