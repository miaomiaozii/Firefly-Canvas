# 【父票】Agent TUI（画布内智能体节点）可用性总览 — 用户实测四大症状 + 审计补充

提出人：项目维护者（要求全方面检查 Agent TUI，用户实测问题为主）；QA 实操验证：Tabbit 浏览器，2026-11-13，用户真实画布。

## 背景
Agent 节点 = 画布内嵌的智能体对话卡片（发送/追问/回退/思考模式/附件）。用户实测报告四大症状，QA 全部复现并定位根因：

1. 卡片不填满节点外框（宽度失配）→ 子票 atui-1
2. 输入框固定 30-36px 不增长 → 子票 atui-2
3. 任何刷新重建节点：草稿被吞、滚动复位（用户表述「取消选择才显示」）→ 子票 atui-3
4. 图标/视觉不统一、样式层混乱 → 子票 atui-5

审计额外发现（按严重度）：
- S1 节点一键删除无确认（QA 实操真实误删过，Ctrl+Z 恢复）→ 子票 atui-4
- 长对话无法翻阅（滚动三因复合，并入 atui-3）
- 按钮聚焦时 Delete 键删节点（并入 atui-4）
- 刷新丢会话历史、渲染自动拉起后端会话、附件无进度、fork 原生弹窗、无障碍 → 子票 atui-6
