# 【Agent TUI】任何刷新/后台事件都重建节点：输入草稿被抹、对话区跳回顶部

验证人：QA（Tabbit 实操实测，2026-11-13）。严重度 S2。

## 发生了什么
- 在输入框输入草稿后点击画布空白处（取消选择），草稿被清空（实测）。
- 后台任意事件（流式输出、状态变化）都会整节点重建，正在输入的内容、光标、输入法组合态一并丢失。
- 每次重建后对话区跳回顶部：自动滚动目标绑错元素（滚的是不可滚动的消息容器），真正的滚动容器重建即复位。长对话实际无法回看（滚轮在节点内被画布缩放拦截、白名单不含 Agent 消息区）。
- 用户报告的「打字内容取消选择后才显示」= 选择期间输入框被反复重建重置，取消选择触发的整画布渲染里只剩消息历史稳定可见（QA 判定为最吻合解释，见补充）。

## 我期望看到什么
草稿、光标、阅读位置在任何刷新后完整保留。

## 复现步骤
1. 选中 Agent 节点，输入框打字（不发送）
2. 点击画布空白处 → 实际结果：草稿消失（对照测试：先选中节点标题再取消，同样清空）
3. 对话超一屏后向上滚 → 实际结果：滚不动或跳回顶部

QA 实测数值（两轮对照实验，均复现）：
- 实验 A：草稿→点节点标题（选中）→输入框值保留；→点画布空白（取消）→输入框值变空字符串。
- 实验 B：`fill` 6 行草稿→取消选择→`el.value` 从 `QA draft...` 变为 `""`（evaluate 直读 DOM 确认）。
实拍补充：输入态见 `.qa/shots/04_agent_input_overflow.png`；草稿清空瞬间实拍因截图通道超时未拍到（数值证据已留存，关票前需补实拍）。

## 补充信息
- 根因链：取消选择 → static/js/smart-canvas.js:14430-14437 `shell.onclick` → `clearSelection()` + `render()` 整节点模板重建 → 输入框重建为空。重复选中已选节点只 `syncSelectionUi()` 不重建（与实测吻合）。
- 节点渲染函数对每个后台事件都整块重建 innerHTML（static/js/canvas-agent-tui.js:1199-1233，19 处调用点）；每节点状态对象（:17-39）无草稿字段。
- 修复方向：草稿持久化进每节点状态（参照全局输入框的草稿保存模式）；增量更新代替整块重建；修正自动滚动目标（:1222-1225 滚错元素）；滚动白名单（static/js/smart-canvas.js:15098-15126）加入 Agent 消息区。
- 输入法（IME 组合输入）在重建时同样被杀——中文用户体验最差。
